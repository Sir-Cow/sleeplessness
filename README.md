## 🌕 Sleeplessness

**This mod adds an additional step to the sleeping process to prevent players from skipping the first few nights while also providing a powerful boon for sleeping.**

### 🛏️ Sleep Changes

Players can no longer sleep in a bed naturally. Beds will still set the player's spawn when interacted with.

### 💭 Dreamcatchers

Dreamcatchers are crafted using sticks, feathers, and hollow twine, which is a new item that can be crafted using phantom membrane. Dreamcatchers allow the player to sleep in a bed granting them the Well Rested effect afterwards.

### 💤 Well Rested

While affected by Well Rested, the player obtains keep inventory until they die or until the effect is dispelled. Well Rested can only be obtained through sleeping.

## ⚙️ Modpack Usage

Sleeplessness is free to be used in any custom mod packs as long as credit is provided. 

Sleeplessness has compatibility with the following mods:

- [Curios](https://modrinth.com/mod/curios)

Compatibility with other mods has not been tested for.
